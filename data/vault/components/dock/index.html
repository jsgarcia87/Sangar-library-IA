Dock

Gratis

Una barra de íconos que se agrandan bajo el cursor

El ícono más cercano crece, sus vecinos lo acompañan y se apartan, y la barra se estira con ellos, todo con resortes y solo transform. Al hacer clic, el ícono salta con anticipación y aplastamiento, como al abrir una aplicación.

Qué incluye
index.html, dock.css, dock.js, README y licencia
