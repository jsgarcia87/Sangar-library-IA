================================================================================
SANGAR AI & CREATIVE COMPONENTS STUDIO — GUÍA RÁPIDA DE USO
================================================================================
Versión: 2.2 Pro
Sistema de Diseño: Sangar Studio OS (Warm Studio OS)
Recursos integrados: Creadores Digitales IA & Galería de Referencias UI con Prompts de Agentes

DESCRIPCIÓN GENERAL:
Sangar AI & Creative Components Studio es una plataforma integral de diseño,
motion graphics e ingeniería de interfaces impulsada por Inteligencia Artificial.
Combina generadores paramétricos de prompts, fotogramas clave (Hero Frames),
expresiones matemáticas de After Effects, storyboards de alta retención, un glosario
de físicas visuales y una Galería de Referencias UI con prompts de agentes.

RECURSOS IMPORTADOS DE CREADORES DIGITALES IA
--------------------------------------------------------------------------------
1. 10 Estilos de Animación en Claude / Canvas / Three.js:
   - Pixel art 8-bit con lienzo 135x240 escalado x8.
   - Pizarra con tiza verde y trazos hirvientes (boiling cada 3 fotogramas).
   - Boceto luminoso neón con doble trazo (halo difuso + filamento blanco).
   - PlayStation 2 retro 3D low-poly con flatShading y niebla cálida.
   - Cómic americano con semitono Ben-Day y líneas cinéticas de acción.
   - Vector plano minimalista moderno con conos de luz transparentes.
   - Línea minimalista continua sobre blanco marfil con acento coral.
   - CGI hiperrealista en Three.js con MeshPhysicalMaterial y ACES Filmic.
   - LEGO stop-motion con animación a treses (10 fps reales).
   - 3D explicativo isométrico pastel con RoundedBoxGeometry.
   - Skill Maestra animacion-estilos (regla de zancada, tiempo dependiente de f y grabador).

2. Generación de Vídeo con Higgsfield AI:
   - Conexión vía MCP/Conectores en Claude.
   - Prompts de lujo 9:16 (perfume oro líquido en cámara lenta), UGC y cine.

3. Vídeos 3D con Remotion (@remotion/three):
   - Pipeline de 5 pasos en código React sin After Effects ni Blender.
   - Renderizado GPU mediante npx remotion render --gl=angle.

4. Diseños Web Profesionales con Claude Code:
   - Integración de Taste Skill, Impeccable UI y Emil Kowalski skills.
   - Automatización y verificación con servidores MCP de Figma y Playwright.

5. 3 Sistemas SaaS / Apps Virales:
   - Comparador de precios y afiliados en Next.js.
   - Trend Radar para creadores de contenido (Supabase + YouTube API + Claude API).
   - Generador de avatares estilo portada de videojuego (Flux LoRA / Fal.ai).

6. Desarrollo de Videojuegos 3D en 5 Rondas:
   - Metodología iterativa en Vite + Three.js (isla volcánica, sonido, cinemática, IA y planeador).
   - Conector Unreal-MCP para manipular Unreal Engine 5 mediante chat.

--------------------------------------------------------------------------------
REQUISITOS Y EJECUCIÓN
--------------------------------------------------------------------------------
- Para desarrollo con servidor local:
  Ejecutar: python3 server.py
  O: npm start
  Abrir en el navegador:
  * Sangar AI: http://localhost:3000/index.html
  * Galería de Referencias UI: http://localhost:3000/components.html

- Sin servidor (offline / file://):
  Puedes abrir index.html o components.html directamente con doble clic.
  Los archivos app.js, components.js y shell.js contienen datos de respaldo
  e iconos incrustados para operar al 100% sin servidor ni conexión.

--------------------------------------------------------------------------------
ACCESIBILIDAD Y SISTEMA DE DISEÑO
--------------------------------------------------------------------------------
- Cumplimiento WCAG 2.1 AA (contraste mínimo 4.5:1 en texto normal y 3:1 en gráficos).
- Atributos ARIA (aria-expanded, aria-selected, aria-live="polite", roles semánticos).
- Navegación por teclado completa (Tab, Shift+Tab, Enter, Escape).
- Atajo global de paleta de comandos: Command+K (Mac) / Ctrl+K (Windows/Linux).
- Fuentes corporativas locales: Stinger Fit Light y Raleway en public/assets/fonts/.
